📋 O que é este projeto?

Um sistema web completo para gerenciar até 100+ imóveis alugados com:
✓ Cadastro de imóveis, proprietários, inquilinos
✓ Contratos com reajuste automático (IGPM/IPCA)
✓ Pagamentos mensais e controle de atrasos
✓ Manutenções e contas de água/energia
✓ Upload de fotos e documentos
✓ Gestão de equipe (permissões por papel)
✓ Lei do Inquilinato (Lei 8.245/91)

Tech: Next.js + Supabase + Vercel

---

🚀 Comece aqui:

1. Instale dependências:
   npm install

2. Crie uma conta Supabase (gratuita) em supabase.com

3. Copie o arquivo .env.example para .env.local:
   cp .env.example .env.local

4. Preencha as variáveis de ambiente:
   NEXT_PUBLIC_SUPABASE_URL=https://seu-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...

5. No console Supabase, execute a migration SQL:
   - Vá a SQL Editor
   - Copie tudo de: supabase/migrations/0001_init.sql
   - Cole e execute

6. Crie o bucket de arquivos:
   - Vá a Storage → Buckets
   - Clique "New Bucket"
   - Nome: arquivos
   - Marque "Public" para leitura

7. Rode o projeto localmente:
   npm run dev

8. Abra http://localhost:3000/login

9. Convide o seu primeiro usuário:
   - Vá ao console Supabase
   - Authentication → Users
   - Clique "Invite user"
   - Convide seu e-mail

10. Mude o papel para admin:
    - Vá a Database → Profiles
        - Encontre seu usuário
    - Mude 'papel' para 'admin' e 'ativo' para true

11. Faça login!

🌐 Publicar na Vercel (depois de testar localmente):

1. Faça push para GitHub:
   git add .
   git commit -m "Initial commit"
   git push

2. Vá a vercel.com/new
3. Importe seu repositório
4. Adicione as variáveis de ambiente (Supabase)
5. Clique Deploy

Seu app estará em: https://seu-projeto.vercel.app

---

❓ Dúvidas comuns:

P: Erro "Cannot find Supabase"?
R: Verifique se .env.local existe e tem NEXT_PUBLIC_SUPABASE_URL e NEXT_PUBLIC_SUPABASE_ANON_KEY

P: Não consigo fazer login?
R: O usuário precisa existir em Supabase Auth E ter o perfil com ativo=true em Database → Profiles

P: Qual é o limite para enviar arquivos?
R: Até 40 MB por arquivo. O envio é feito ao Supabase Storage.

P: Reajuste não é calculado?
R: Cadastre os índices mensais em "Índices" antes. O sistema lê dali.
